# 調べものバー (Quick Lookup Bar)

macOS用の調べものランチャーです。Shiftを2回押すと画面中央に入力欄が開き、打った言葉をすぐ各サービスに送れます。開くたびに「物書堂 辞書」が選ばれ、言葉を入力してEnterを押すと物書堂で検索します。

| キー | 送り先 |
| --- | --- |
| Shift+1 | 辞書 by 物書堂（全辞書・前方一致） |
| Shift+2 | ChatGPT（Web） |
| Shift+3 | Claude |
| Shift+4 | Grok |
| Shift+5 | Google |
| Shift+6 | ChatGPTアプリの「あなたのdot」 |
| Shift+7 | Grok Botアプリの入力欄 |
| Shift+8 | 音声入力（ChatGPTへ送信） |

Shiftを2回押して開くと、入力欄にカーソルが移り、クリックせずに文字を入力できます。

検索先ボタンのクリックまたはShift＋数字で検索先を選び、検索ボタンかEnterで実行します。選ぶだけでは送信しません。Escで閉じます。テンキーの数字にも対応しています。

キーボードでの検索先選択はShift＋数字です。数字だけ、Command＋数字、Control＋数字では検索先を切り替えません。

入力欄は開くたびに空になります。コピーした内容は自動表示せず、必要なときに⌘Vで貼り付けます。クリップボード自体の内容は変更しません。

入力画面はヒラギノ丸ゴを使い、入力欄と小さな検索先ボタンを中心にしたコンパクトな配置です。ヒラギノ丸ゴがない環境ではシステムフォントへ切り替わります。音声入力の送信先は選択中の検索先によらずChatGPT Webです。

## 検索先の設定

入力画面の歯車、またはアプリメニューの「設定…」（⌘,）から開きます。検索先の追加、上下移動、名前、表示の有効・無効、選択キー、初期検索先を設定できます。

- 並べ替えてもキーと初期検索先は変わりません。初期検索先の標準値は物書堂です。
- Web検索先を追加するときは `https://example.com/search?q={query}` のように、HTTPS URLのクエリ値へ `{query}` を1個入れます。追加先は最初はキー未割当です。
- ⇧8は音声用に予約しています。選択キーは未割当、⇧1〜7、⇧9から重複しないよう選びます。非表示の検索先も割当を保持します。
- 標準検索先は削除せず、表示をオフにできます。追加した検索先は確認後に削除できます。削除や編集は「保存」で確定し、「キャンセル」で戻せます。
- 「標準の名前に戻す」は選択中の標準検索先の名前だけを戻します。キー、並び、追加先は変えません。
- メニューバーに単色アイコンを表示する設定もあります。初期状態は従来どおり非表示です。
- 設定はUserDefaultsへ保存します。入力欄の検索履歴は保存しません。設定が破損している場合は元データを保持して標準値で起動し、設定画面に案内を表示します。

Shiftの2回押しは、他のアプリへも割り当てられている場合に競合します。他アプリ側の設定も確認してください。

## ビルド

```sh
./build.sh
# 署名IDを指定する場合
SIGN_ID="Apple Development: ..." ./build.sh
# インストールせず別の場所に出力
APP_OUTPUT="$PWD/.build/調べものバー.app" ./build.sh
```

初回はシステム設定の「アクセシビリティ」で 調べものバー.app を許可してください（Shiftの2回押しと他アプリへの入力に必要です）。音声入力にはマイクと音声認識の許可が必要です。

## 検証

```sh
bash tests/run.sh
```

設定とネイティブ画面のロジックを隔離したUserDefaultsで確認します。テスト中にシステムのクリップボードを読まず、音声入力、検索URLへの接続、他アプリへの送信、グローバルキー操作は行いません。

組み立てたアプリの `Contents/MacOS/QuickLookupBar --render-preview <出力フォルダ>` で、パネルと設定画面のオフスクリーン描画を保存できます。これは実画面でのキー操作や他アプリ連携の検証とは別です。
